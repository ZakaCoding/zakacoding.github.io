The idea behind Craft

The space between
“what if” and “there it is.”

You have the idea. Then come the blank canvas, the first draft, the copy tweaks, and all the little decisions in between.

Craft brings a conversation into that space. It lives inside Design Studio, so you can ask for a plan, work through your copy, review suggested edits, or create a first design without leaving the editor.

I’m building it for independent makers and small teams who move between design and development. The goal is a shorter path to a useful first version, while keeping the result open to your own judgment.

Apply, inspect & verify

01 Let the model describe. Let the compiler build.+

For new designs, the model produces a structured brief: copy, palette, typography and section choices. Craft’s compiler turns that brief into a validated layout, then fixed gateway scripts create native Penpot layers.

This separates a model’s language output from the geometry and code that touch a design. The compiler handles layout rules, font selection and contrast checks. Today’s library is bounded; broader layout variety and iterative refinement remain development work.

02 Make approval a boundary the system enforces.+

Reading a page and proposing a change are separate from applying it. Proposals are bound to the user and target, expire, and can be applied once. The canvas gateway checks the active file and page before writing.

After applying, Craft reads the affected layers to verify the outcome. Partial or uncertain operations are reported explicitly, so an incomplete edit is not presented as a successful one.

03 Account for usage before sending the request.+

Craft Managed uses Cloudflare Workers AI through AI Gateway. The application reserves an estimated allowance before inference and settles confirmed usage afterwards. Studio Credits & Usage makes that accounting visible.

Application budgets sit alongside provider controls. The system handles exhausted limits and unresolved usage as explicit states. Applying an already-approved proposal does not trigger another model call.

04 Build the operational layer around the product.+

Cloudflare protects the public entry with DNS, edge controls and a separate Access-protected developer gateway. R2 holds encrypted off-server backups. The editor and Craft application run on VPS infrastructure.

Penpot provides the open-source design foundation. ZakaCoding develops and operates the hosted experience, Craft, account flows, usage accounting and the gateway integration independently.

Built. Used. Still becoming.

A real product in its early chapters, with a lot left to learn from the people using it.

Available in the early product

Conversation and planning, approval-based text and layer-name edits, Studio Credits & Usage, and the first Create Design workflow. Design Studio access is by invitation; Craft availability depends on the member’s enabled access and allowance.

What I’m working toward

More visual directions, stronger first drafts, and a refinement loop that builds on an existing design. The current priority is output quality and dependable canvas behavior, before opening access more widely.

The product direction is a hosted design workspace with managed AI usage through Studio Credits, built for makers and small teams. Access and the commercial model are developing alongside the early product.

Product snapshot · 26 October 2026. Design-generation examples above use offline fixtures. Live model quality, wider device coverage and multi-member reliability are still being evaluated.
